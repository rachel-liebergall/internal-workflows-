## Status and execution

Repository documentation does not by itself prove that a schedule is enabled or that a run succeeded. The directory records the evidence available as of **October 14, 2026**. Most older Claude routines still need live status verification. Baxter's reflection README records its October 11 hosted rollout checks; the Monday Substack automation was configured in Codex on October 14 and awaits its first scheduled run.

GitHub holds reviewable instructions and operating notes. Slack-hosted apps, Claude routines, and Codex automations execute the workflows. Changes proposed in a pull request appear on its branch until merged; they do not automatically deploy to those runtimes.

Keep private runtime configuration, tokens, transcripts, and operational identifiers out of this public repository.
